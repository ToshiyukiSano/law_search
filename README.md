# 法令検索・条文読み上げ

e-Gov 法令 API を使って日本の法令を検索・閲覧し、条文を音声で読み上げる Web アプリです。
HTML・CSS・JavaScript だけで動く静的サイトで、ビルドやサーバー側の処理は必要ありません。

## 主な機能

### 法令の検索・閲覧
- 法令名で検索（初回に法令一覧を取得し、1日キャッシュ）
- 憲法・民法・刑法・商法・会社法・民事訴訟法・刑事訴訟法へのショートカット
- 目次から編・章・節・款・目へ移動
- 条番号を入力して移動（例: `1`、`3_2`（第三条の二）、`0`（目次）、`00`（前文）、`000`（附則））
- 本文のキーワード検索（スペース区切りで AND 検索、該当する条を順に移動）
- 条の見出しをクリックすると、その条への URL をコピー
- 未施行の改正法の附則の表示・非表示

### 条文の読み上げ
- 画面下部のプレイヤーで再生・一時停止・停止、前の条・次の条へ移動
- 各条の見出し横の ▶ から、その条を読み上げ
- 読み上げ中の箇所をハイライトし、自動でスクロール
- 章・節・附則などの見出しも読み、項は「第2項」、号は「第一号」として読む
- **ブックマーク・続きから再生**：読み上げ位置を法令ごとに自動保存し、次に開いたときに続きから聞ける
- トップページに「聞きかけの法令」を一覧表示
- **読み上げ速度**：0.5〜2.0 倍（0.05 倍刻み）
- 音声の選択と試聴
- スペースキーで再生・一時停止

詳しい操作方法は [manual.html](manual.html)（アプリ内の「使い方」）を参照してください。

## ローカルで動かす

e-Gov API からデータを取得するため、HTML ファイルを直接開く（`file://`）のではなく、簡易サーバー経由で開いてください。

```bash
git clone https://github.com/ToshiyukiSano/law_search.git
cd law_search
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。

同じ Wi-Fi につないだスマートフォンからは、`http://<PCのIPアドレス>:8000/` で開けます。

GitHub Pages などの静的ホスティングにそのまま置いても動きます。

## ファイル構成

```
index.html      トップページ（法令検索、聞きかけの法令）
law.html        法令表示画面（本文、条番号移動、キーワード検索、読み上げプレイヤー）
manual.html     使い方
css/style.css   スタイル
js/main.js      トップページの処理
js/viewer.js    法令 XML の取得と描画、移動、検索
js/reader.js    読み上げプレイヤー（Web Speech API）
js/manual.js    使い方ページの処理
img/arrow.svg   ページトップボタンのアイコン
```

`viewer.js` は本文を描画し終えると `law:rendered`、改正法の表示を切り替えると `law:changed` というイベントを `document` に送ります。`reader.js` はこれを受けて、読み上げる文の一覧を作り直します。

## データの保存

設定とブックマークは、ブラウザの localStorage に保存されます。サーバーには何も送りません。別の端末やブラウザとは共有されません。

| キー | 内容 |
|---|---|
| `opt-newtab`、`opt-amended` | トップページ・法令表示の表示設定 |
| `lawlist-cache` | 法令一覧のキャッシュ（1日） |
| `reader-bm-<法令ID>` | 読み上げ位置のブックマーク |
| `reader-bm-index` | ブックマークがある法令 ID の一覧 |
| `reader-rate`、`reader-voice` | 読み上げ速度、選んだ音声 |

## 対応環境と制限

- 読み上げにはブラウザの音声合成機能（Web Speech API）を使います。声の質や速くしたときの聞きやすさは、OS とブラウザに入っている音声によって大きく変わります。
  - Ubuntu の Chromium・Firefox（espeak）では、速くすると聞き取りにくくなります。
  - iPhone の Safari では Kyoko などの音声が使えます。「設定 → アクセシビリティ → 読み上げコンテンツ → 声」で高品質版をダウンロードすると、一覧に出てくることがあります。
- **iPhone では、消音モードを解除しないと音が出ません。**
- スマートフォンでは、画面ロックやアプリの切り替えで読み上げが止まることがあります（止まった位置は保存されます）。
- 前文・附則など一部の条文は、レイアウトや書式が原文と異なる場合があります。

## データの出典

法令データは [e-Gov 法令 API](https://laws.e-gov.go.jp/)（`https://laws.e-gov.go.jp/api/1/`）から取得しています。正確な法令文は [e-Gov 法令検索](https://laws.e-gov.go.jp/) で確認してください。
